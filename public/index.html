Como se joga
  1. O Dono da Palavra escolhe uma palavra secreta e revela só a primeira letra.
  2. Os caçadores escrevem dicas: a definição de uma palavra que comece com as letras já reveladas (sem dizer a palavra!).
  3. Quem acha que descobriu a palavra de uma dica clica em CONTATO e envia seu palpite.
  4. O Dono tem alguns segundos para bloquear, dizendo a palavra da dica. Se acertar, o contato é anulado (+2 pra ele).
  5. Se o bloqueio falhar e autor + contatante tiverem escrito a mesma palavra, mais uma letra é revelada (+1 pra cada).
  6. Quem descobrir a palavra secreta pode arriscar a qualquer momento (+3 se acertar, −1 se errar).
  7. A rodada acaba quando a palavra é adivinhada ou revelada por inteiro. Depois o posto de Dono passa adiante.
